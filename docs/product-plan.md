# 产品计划：新生日历

**新生日历**给第一次当父母、父母对等的家庭：从怀孕到孩子 7 岁，按事项的「最早需要日（T0）」提前把该准备、该学的内容送到微信小程序。每条内容都标明**给父亲**或**给母亲**；**任意一个已登录的微信都能看到家庭里两种角色的副本**，不把内容按微信号隔离。

微信通道已锁定为 **方案 A（小程序 + 一次性订阅消息）**，详见 [微信触达与配置选项](./wechat-delivery-options.md)、[MVP 范围](./mvp-scope.md)、[小程序信息架构](./mini-program-ia.md)。

---

## 1. 名称、定位与范围

| | 已锁定 |
| --- | --- |
| 产品名 | **新生日历** |
| 用户 | **父母对等** |
| 内容标注 | 每条标明 **给父亲** 或 **给母亲** |
| 查看 | **一个微信可看父母双方副本**；第二人微信可选，不是看双方内容的前提 |
| 内容深度 | **A**：孕晚期→1 岁做细；1 岁→7 岁仅阶段骨架 |
| 微信 | **方案 A**：个人/个体小程序 + 一次性订阅；无企业、无服务号/订阅号 |

**一句话定位**  
给没有生育/养育经验的父亲和母亲各准备一套按阶段的事项（始终标明给谁），在最早可能用上之前推到微信；T0 当天最后一次告知后停止。一个人用也能看全两套。

### 谁在范围内 / 谁不在

**在范围内**

- 第一胎怀孕、备产，或已有一名 0–7 岁孩子、自认为没带过孩子的父亲和/或母亲
- 可一人用一个微信看全家内容；也可选再加一个微信登录同一家庭
- 中国大陆微信；地区 **上海** 或 **其他**

**不在本期范围**

- 二孩及以上、已有完整带养经验
- 医护、月嫂、托育当主用户；8 岁及以上学科辅导
- 诊断、开药、替代就诊
- 独立 App / 短信；**企业认证服务号、同期服务号、订阅号/服务号品牌号**（主体无公司）

## 2. 用户与家庭模型

**家庭 = 1 个焦点孩子 + 两套角色内容（父亲 / 母亲）+ 1～2 个微信登录。**  
推荐由共享孩子档案、两套家长状态、临时标签决定推什么、何时推、用上海还是全国兜底。

### 2.1 角色与查看（已锁定：共享查看）

| 规则 | 说明 |
| --- | --- |
| 内容角色 | 事项绑定 **给父亲 / 给母亲 / 双方**（双方则两条，各标一个角色） |
| 标注 | 推送与详情里**每条都出现「给父亲」或「给母亲」**，避免不知道是谁的任务 |
| 一个微信 | **可浏览、勾选、学习父母双方的副本**，不要求第二个微信号 |
| 可选第二微信 | 另一人用自己的微信登录**同一家庭**，看到的也是**整户两套角色**，不是「只能看自己角色」 |
| 不是 | 不再要求「第二接收人必须各自微信才能看对方内容」；角色**不是**按微信号隔离的收件箱 |
| 登录用途 | 第二微信只为「另一部手机也能打开同一本日历、也能收服务通知」，不是权限墙 |
| 静音 | **按微信登录**（这部微信的提醒停不停）；静音**不打破**。静音不隐藏日历里另一角色的内容 |
| 档案 | 孩子档案全家共享；父亲/母亲状态是家庭上的两套资料，任一登录都可改（方便一人代填） |

### 2.2 地区（v1）

| 选项 | 口径 |
| --- | --- |
| **上海** | 上海产检/接种/入园等地方口径 |
| **其他** | 全国共性兜底，标明「以当地社区/医院/教育局为准」 |

不维护长城市列表。改地区：未发送事项按新口径重算；已发送不自动重推，除非点「按新地区刷新未完成项」。

### 2.3 孩子当前状态（共享）

| 字段 | 说明 | 对推荐的影响 |
| --- | --- | --- |
| 阶段 | 孕期 / 新生儿 / 婴儿 / 幼儿 / 学龄前 / 小学低年级 | 选内容池 |
| 预产期 | 孕期必填 | 孕期 T0 |
| 出生日期 | 出生后覆盖预产期 | 0–7 岁按月龄/年龄 |
| 孕周 / 月龄（派生） | 只读 | 产检、辅食、入园等 |
| 照护形态（可选） | 父母自带 / 隔代 / 托育+家庭 | 技能侧重点 |

MVP 单孩。

### 2.4 家长状态（家庭上两套，非按微信隔离）

| 字段 | 说明 | 对推荐的影响 |
| --- | --- | --- |
| 角色资料 | 父亲一套、母亲一套 | 生成「给父亲」「给母亲」文案 |
| 身体与假期 | 在岗、产假、陪产假、哺乳假、已返岗 | 匹配该角色的事项 |
| 经验 / 顾虑 | 可按角色填 | 技能拆步、主题加权 |

怀孕事项不是只写给母亲：陪产、证件、护理预习等按绑定角色出内容，**查看上双方都可见**。

### 2.5 临时情境（预设 + 1 个自定义）

可随时加、带有效期，到期失效，不改生日/预产期。

| 预设标签（点选） | 有效期建议 | 影响 |
| --- | --- | --- |
| 疫苗后观察 | 3–7 天 | 观察类科普（免责）；推迟强运动技能 |
| 回老家 / 出行 | 行程天数 | 推迟本地线下 |
| 住院待产 | 住院天数 | 入院清单优先 |
| 隔代来住 | 重叠期 | 交接与协同 |
| 月嫂结束 | 1–2 周 | 自己上手过渡 |
| 想降量 | 1–3 天 | 合并后更短 |
| 静音 | 用户自设 | **该微信**期间不发提醒（见第 4 节） |

自定义全家庭同时 **1 个**短标签。不当病历、不开处方。不适只用预设观察类，导向就医。

## 3. 时间轴与「最早需要时间」

### 3.1 阶段（怀孕 → 7 岁）

| 阶段 | 时间窗 | v1 内容策略（深度 A） |
| --- | --- | --- |
| 孕早期～孕中期 | 孕 0–27 周 | **骨架**：关键节点标题即可，不深写 |
| 孕晚期 | 孕 28 周–分娩 | **做细** |
| 待产窗口 | 预产期前后 | **做细** |
| 新生儿～1 岁 | 0–12 月龄 | **做细** |
| 1 岁→7 岁 | 幼儿～小学低年级 | **仅阶段骨架** + 少量行政「其他」（如入园入学名） |

阶段选内容池；发送时刻 = T0 + 品类节奏。

### 3.2 T0

每条有 NeedAnchor → **T0 = 最早需要日**（下限，非平均、非最晚）。

1. 相对孕周：预产期倒推到该孕周对应日（全库同一日历规则）。  
2. 相对月龄/年龄：生日 + 整月/整岁。  
3. 政策窗口：上海用上海当年窗口起始；「其他」不写死外地截止日期。  
4. 相对家长节点：如返岗日 → 进入对应**角色**的事项（查看仍全家可见）。

出生后未发送事项用实际生日重算；已发不撤回。改预产期只排尚未发生且 ≤ T0 的节拍。

**节拍均 ≤ T0**：T-14、T-7、T0。科普自 T-14 每 3 天，T0 不在序列则补 T0，然后停。无 T0 之后、无「需要周再推」。

---

## 4. 内容分类与推送节奏

到达 T0：该条**最后一次通知然后停止**。

| 类型 | 节拍（均 ≤ T0） |
| --- | --- |
| **技能** | T-14、T-7、**T0** |
| **科普** | T-14 起每 3 天，**含 T0 后停** |
| **其他** | T-14、T-7；若仍到不了「窗口已到」则 **加 T0** |

最后一触在 T0 或更早。行政日不能错过则把 T0 设在必须告知的那天，不在 T0 后再催。

### 合并、订阅票、静音

- 同一微信、同一自然日：父亲条 + 母亲条 **合并成 1 条**服务通知（条目仍各标角色），**每个微信每天 ≤ 1 条**。  
- 夜间 21:00–8:00 延到次日上午；若已过 T0 则进补课包、不推。  
- **一次性订阅**：每条服务通知消耗该微信已同意的票。打开小程序时可再申请续票。  
- **已接受**：若用户不回来打开小程序续票，**提醒停止，直到回来**。不改用客服消息、不破静音、不做服务号模板补发。  
- **静音**（按微信）：期间一条提醒都不发；结束不清积压，每条内容最多补 1 次仍 ≤ T0 的最近节拍。  
- 晚注册：只发未发生且 ≤ T0 的节拍；已过 T0 进补课包，该微信最多 1 条汇总（条目仍标父亲/母亲）。

## 5. 微信交付（已锁定方案 A）

- 配置与阅读：**个人/个体主体小程序**（无公司，不能走企业认证服务号模板路径）。  
- 到达：**一次性订阅消息** → 微信「服务通知」→ 点进小程序。  
- **不做**：企业认证服务号、同期服务号、订阅号/服务号品牌号、客服当日历通道、长期订阅赌医疗类目。  
- 消息结构：角色标签 + 阶段 + 今天做什么 + 为何是现在 + 打开详情。  
- 主体约束见微信文档；通道细节以该文档为准。

## 6. MVP vs 后期

**闭环：** 一孩、上海或「其他」、一人或两人微信、小程序档案 + 一次性订阅。

1. 打开小程序，建家庭（孩子 + 父亲/母亲两套状态，可先填一套）。  
2. 授权一次性订阅；同意后才有票。  
3. 生成至各事项 T0 的节拍；已过 T0 进补课包。  
4. 日历里**同时列出给父亲/给母亲**；推送合并进该微信的日更。  
5. 预设标签 + 1 自定义、按微信静音。  
6. 可选邀请第二微信登录同一家庭（同样能看两套、同样自己续票）。

**内容深度 A（已锁定）：** 孕晚期→1 岁做细（待产、新生儿护理、喂养、疫苗口径、辅食启动等）；1 岁→7 岁只有阶段骨架 + 少量行政名。

**MVP 不做：** 多孩、社区、带货、AI 问诊、硬件、多城市百科、公众号矩阵。

后期：加厚 1–7 岁、扩城市、隔代模式。仍非诊疗。

## 7. 风险

**医疗**：日历不是问诊；禁剂量/处方；急救含打急救电话；标签不当病历。

**政策**：仅上海精细 + 其他兜底；兜底写「以当地为准」。

**隐私**：预产期/生日/标签敏感；地区只到上海/其他。订阅字段只写摘要。任一登录可见全家两套角色内容——邀请第二微信即共享这本日历，需用户知情。注销删档。不用数据做医疗广告。

**主体与到达**：个人/个体小程序没有服务号模板兜底；断票后提醒必停，产品上只在小程序内提示续订。
