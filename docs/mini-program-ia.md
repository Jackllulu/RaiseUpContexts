# 新生日历：小程序信息架构（MVP）

页面与模块怎么拼，不是视觉稿，也不是接口。规则见 [产品计划](./product-plan.md)、[MVP 范围](./mvp-scope.md)、[微信触达](./wechat-delivery-options.md)。

**已锁定（架构必须遵守）**  
个人小程序 + 一次性订阅；无公众号。一个微信看「给父亲 / 给母亲」两套。第二微信可选、进同一家庭。静音按微信且不打破。无票则提醒停，日历仍可看。

---

## 站点地图

```
启动（微信登录）
 ├─ 无家庭 → 创建家庭向导 → 日历
 ├─ 持邀请进入 → 加入家庭确认 → 日历
 └─ 已有家庭 → 日历（主页）

底部三栏（有家庭后）
 ├─ 日历
 │    ├─ 事项详情（技能 / 科普 / 其他）
 │    └─ 补课包
 ├─ 家庭
 │    ├─ 孩子档案
 │    ├─ 父亲资料 / 母亲资料
 │    └─ 情境标签
 └─ 我的
      ├─ 提醒与续票
      ├─ 静音
      ├─ 邀请第二微信
      ├─ 免责声明
      └─ 退出家庭 / 注销
```

服务通知点进来：有票无票都进**事项详情**或**日历当日**；无家庭则进创建向导。

**页面共 12 个**（向导算 1 页多步；父亲/母亲资料可同一页两段，仍单列「家长资料」）。

---

## 首次 vs 再次进入

| | 首次（该微信尚无家庭） | 再次（已加入某家庭） |
| --- | --- | --- |
| 落地 | 创建家庭向导；或邀请确认 | 日历；可从通知进详情 |
| 订阅 | 向导末步请一次授权；可跳过 | 打开日历/详情/保存档案后可再申请续票 |
| 档案 | 地区 + 孩子锚点必填；父母两套可只填一侧 | 家庭栏随时改 |
| 缺票 | 跳过订阅也能用日历，横幅「尚未开启提醒」 | 横幅「提醒已停，点此续订」；不拦阅读 |

## 页面说明

### 1. 启动

**目的** 微信登录，判断有无家庭、有无邀请。  
**进** 打开小程序、通知、邀请链。  
**出** 向导 / 加入确认 / 日历。  
**异常** 登录失败 → 重试，不进日历。

### 2. 创建家庭向导（首次）

**目的** 建一孩家庭，立刻能出日历。  
**模块** 地区（上海/其他）→ 孩子预产期或生日（派生阶段）→ 可选照护形态 → 父亲/母亲资料可跳过 → 请开一次性订阅。  
**出** 完成 → 日历；中途退出 → 未建档，下次仍从向导开始。  
**空态** 未填锚点不能完成（无法算 T0）。

### 3. 加入家庭（第二微信）

**目的** 用邀请进入**同一家庭**，看到两套角色，不是开通「对方收件箱」。  
**进** 邀请码/链接。  
**出** 确认 → 日历；拒绝/失效 → 说明原因，可改为自己创建家庭。  
**异常** 家庭已有 2 个微信 → 不可再加；自己已在别的家庭 → 先退出再加入（MVP 一微信一家庭）。

### 4. 日历（主页）

**目的** 同一列表看给父亲、给母亲的事项与节拍。  
**进** 底栏、从详情返回、通知进当日。  
**模块** 阶段摘要（如孕 32 周）；筛选（全部 / 仅父亲 / 仅母亲，默认全部，**不是权限隔离**）；今日与即将（≤T0）；条目：角色标签、类型（技能/科普/其他）、距 T0、完成勾选；入口：补课包、续票横幅、标签摘要。  
**出** 详情、补课包、家庭、我的。  
**空态** 该阶段无事项（骨架期常见）→ 「这个阶段只有大纲」；无票横幅不挡列表。  
**异常** 档案缺锚点 → 引导去补孩子生日/预产期。

### 5. 事项详情

**目的** 读一条并勾选；高风险文首提示。  
**进** 日历、补课包、服务通知。  
**模块** 「给父亲」或「给母亲」；类型；为何是现在（相对 T0）；正文（细=步骤/清单；骨架=一两句）；免责短句；勾选已准备/已练习；返回后续票（非静音时）。  
**出** 回日历或补课包。  
**空/错** 内容下架 → 「已撤下」；已过 T0 仍可从补课包打开，不再承诺会推送。

### 6. 补课包

**目的** 已过 T0、未完成事项的一次性汇总，不按原节奏连推。  
**进** 日历入口；晚注册后可能从「1 条汇总通知」进来。  
**模块** 按角色分组的列表；点进详情；全部完成则空态「没有需要补看的」。  
**出** 详情、日历。

### 7. 家庭（档案总览）

**目的** 一页看懂孩子 + 父母两套 + 当前标签。  
**模块** 孩子卡片；父亲卡片 / 母亲卡片（空则「未填，仍可看该角色内容」）；当前预设标签与 1 个自定义；「按新地区刷新未完成项」。  
**出** 孩子档案、家长资料、情境标签。

### 8. 孩子档案

**目的** 改地区、预产期、生日、照护形态。  
**出** 保存回家庭；未发送节拍按新锚点重算。  
**错** 预产期与生日逻辑冲突 → 说明出生后以生日为准。

### 9. 家长资料（父亲 / 母亲两套，可一页两段或两个子页）

**目的** 假期节点、经验、顾虑；任一微信可代填。  
**出** 保存回家庭。允许一侧全空。

### 10. 情境标签

**目的** 点选预设 + 全家庭 1 个自定义（有效期）。  
**模块** 预设列表；自定义槽位（已有则替换说明）；到期展示。  
**出** 家庭/日历。自定义不当病历提示。

### 11. 我的 · 提醒与续票

**目的** 看本微信订阅是否够用；手动续票。  
**模块** 有票/无票状态；「打开后续票」说明；**接受断票即停**的一句解释；不提供客服补发。  
**静音中** 不发起订阅弹窗，文案改为「静音结束后再续订」。

### 12. 我的 · 静音 / 邀请 / 免责 / 退出

**静音** 本微信的时段或日期；预告「期间任何提醒都不发」；不提供「截止例外」。  
**邀请第二微信** 生成邀请；已有两人则停发；说明对方将看到全家两套内容。  
**免责声明** 全文：非问诊、不替代就诊、上海/其他口径差异。详情页高风险仅摘要+链到此页。  
**退出家庭** 本微信解绑，另一微信不受影响。  
**注销** 删档说明后执行。

## 关键模块（跨页）

| 模块 | 出现位置 | 要点 |
| --- | --- | --- |
| 家庭 | 向导、家庭栏、邀请 | 一孩、1～2 微信 |
| 档案（父母两套） | 向导可跳过、家庭、家长资料 | 共享查看、共享可改 |
| 日历双角色 | 日历、筛选、通知合并 | 每条标角色；筛选不是权限 |
| 详情 | 独立页 | 细/骨架厚度不同 |
| 补课包 | 日历入口 + 汇总通知 | 只读过期未完成 |
| 订阅续票 | 向导、打开后、我的 | 无票不拦阅读 |
| 静音 | 我的；日历可显示「已静音」 | 按微信、不打破 |
| 邀请第二微信 | 我的；启动吃邀请链 | 同家庭、同两套内容 |
| 标签 | 家庭、标签页、日历摘要 | 预设 + 1 自定义 |
| 免责 | 详情文首、我的全文 | 非诊疗 |

## 空态 / 错误 / 无票

| 状态 | 用户看到 | 可做 |
| --- | --- | --- |
| 日历无事项 | 骨架期说明 | 去档案、看补课包 |
| 一侧家长未填 | 卡片「未填」 | 仍列出该角色事项 |
| 无票 | 横幅续订 | 用日历；**无服务通知** |
| 静音 | 日历角标「已静音」 | 改资料；不弹订阅 |
| 邀请无效/满员 | 原因 + 回向导或日历 | — |
| 登录/保存失败 | 重试 | 不丢已填项（能保留则保留） |
| 通知对应内容已下架 | 已撤下，回日历 | — |

## 非本架构

公众号菜单、服务号模板页、按微信号拆两个互不可见首页、问诊对话、多孩切换。
