# 新生日历：MVP 范围

本切片要做出可给新手父母用的最小闭环。规则已锁定，见 [产品计划](./product-plan.md)、[微信触达与配置](./wechat-delivery-options.md)；页面结构见 [小程序信息架构](./mini-program-ia.md)。本文只划 **做什么 / 不做什么**，不改那些决定。

---

## 1. MVP 内 / 外

### 必须做

| 项 | 锁定口径 |
| --- | --- |
| 产品 | **新生日历**；父母对等；事项标明 **给父亲 / 给母亲** |
| 载体 | **个人/个体小程序** + **一次性订阅消息**（服务通知） |
| 不做的通道 | 公众号、服务号、订阅号品牌号、企业认证模板、客服当日历 |
| 地区 | **上海** 或 **其他**（全国兜底） |
| 孩子 | 一孩；怀孕到 7 岁时间轴都在，但内容深度见下 |
| 内容深度 A | **孕晚期→1 岁做细**；**1 岁→7 岁仅阶段骨架**；孕早/中期亦为骨架 |
| 节奏 | 技能 T-14 / T-7 / T0；科普 T-14 起每 3 天至 T0；其他 T-14 / T-7（必要时 T0）；**T0 最后一触后停** |
| 到达 | 每微信每天 **≤1 条**合并服务通知；夜间顺延；**静音不打破** |
| 查看 | **一个微信看父母双方副本**；第二微信可选，进同一家庭，同样看两套 |
| 续票 | 打开小程序再申请一次性订阅；**不续则提醒停，直到用户回来** |
| 情境 | 预设标签 + **1 个**自定义；按微信静音 |

### 明确不做（本切片）

企业号矩阵、多孩、社区、带货、AI 问诊、硬件、多城市政策库、1–7 岁写细、把内容按微信号隔离、破静音、用客服/模板补发断票。

## 2. 用户路径

**第一次打开**  
进入小程序 → 创建家庭 → 选地区（上海/其他）→ 填孩子预产期或生日（决定阶段）→ 可先只填父亲或母亲一套状态，另一套可空。日历立刻按已有信息生成。引导一次性订阅：同意才有提醒票；拒绝仍可用日历，只是没有服务通知。

**填档案**  
随时改：地区、预产期/生日、照护形态、父亲/母亲假期与顾虑。改锚点后只重排 **尚未发生且 ≤ T0** 的节拍。已过 T0 的进补课包，不连推。

**日常日历**  
一个列表/日历同时展示「给父亲」「给母亲」。可打开详情（技能步骤 / 科普 / 清单）、勾选已准备或已练习。一人即可看全两套。

**收到合并提醒**  
某日若有节拍：该微信最多 1 条服务通知，内含当日多条摘要（各标角色）→ 点进对应详情。无票则当天不发，日历里事项仍在。

**打开即续票**  
每次有意义的打开（看完、勾选、保存档案）可再申请一次性订阅。票用尽时页内提示续订，不弹静音中的号、不走客服。

**可选第二微信**  
家庭内生成邀请。对方用自己的微信打开并加入**同一家庭**：看同样两套内容、自己授权自己的订阅票、自己设静音。不加入也不影响第一人看双方副本。

**静音**  
按这部微信设时段或日期。期间该微信 0 条提醒（含截止/安全）。日历与标签仍可操作。结束不清积压。

**标签**  
点选预设（如疫苗后观察、出行、住院待产、隔代来住、想降量等）+ 全家庭 1 个自定义短标签。到期失效；影响排序/降量/插入观察向科普，不当病历。

## 3. 功能清单

### 账号与家庭

- 微信登录小程序；一个家庭一份孩子档案  
- 1～2 个微信绑定同一家庭；第二个可选  
- 邀请加入、退出该微信（家庭内容仍留给另一登录，若还有）  
- 注销/删档入口（隐私要求）

### 档案

- 地区：上海 / 其他  
- 孩子：阶段派生、预产期、生日、可选照护形态  
- 家长：父亲一套 + 母亲一套（角色状态、假期节点、经验/顾虑）；可只填一侧  
- 预设标签 + 1 自定义（有效期）

### 日历与事项

- 按 T0 与品类生成节拍；列表同时含两种角色  
- 详情：技能 / 科普 / 其他；勾选完成  
- 补课包：已过 T0 未做完的汇总，不按原节奏连推  
- 晚加入：只排未来 ≤ T0 的节拍

### 推送与续票

- 一次性订阅授权与余票提示  
- 按节拍发服务通知；日合并；文案含角色 + 为何是现在  
- 断票即停；回来续票后只发仍有效且 ≤ T0 的节拍  
- 21:00–8:00 不下发，顺延次日上午（已过 T0 则不发、进补课包）

### 内容范围

- 见第 4 节：细 vs 骨架，不是完整选题表  
- 上海口径用于上海用户的行政/接种窗口；「其他」只用全国共性并写「以当地为准」

### 设置

- 该微信静音（不打破）  
- 邀请第二微信  
- 免责声明与高风险文首提示（日历非问诊）

## 4. 内容 MVP（细 vs 骨架）

不是发稿日历，只规定**厚度**与**类型样例**。每条仍属技能 / 科普 / 其他之一，并标给父亲或给母亲。

| 阶段 | 厚度 | 技能（例） | 科普（例） | 其他（例） |
| --- | --- | --- | --- | --- |
| 孕早、孕中 | **骨架** | 可空或 1 条「何时开始学待产」入口 | 阶段名 + 一句「此时常见安排」 | 「建档/产检」有这么个窗口（不写死外地细则） |
| **孕晚 → 待产** | **细** | 待产包使用、入院陪同、呼吸/用力认知（非替代产房指令） | 分娩常见过程、何时该去医院（红旗） | 证件与待产包清单；上海用户可有地方材料提示 |
| **新生儿 → 1 岁** | **细** | 拍嗝、冲奶/喂养姿势、呛奶急救演练、安抚入睡、辅食添加手法 | 黄疸观察、疫苗在防什么、辅食窗口为何约 6 月龄、睡眠安全 | 接种本/预约提醒口径；上海按上海程序骨架+链接原则，其他用国家免疫规划共性 |
| **1 岁 → 7 岁** | **骨架** | 每阶段 0～1 个「这类技能存在」（如如厕、入园分离）不写长教程 | 阶段一句话（分离焦虑常见、幼小作息） | 入园/入学「有材料窗口」条目名；上海可点名本地窗口，其他只写「问当地园/校」 |

细：步骤或清单可勾选、科普有「现在为何推 + 何时问医生」。  
骨架：标题 + 一两句 + 可选「以后会加细」；不假装已覆盖该年所有准备。

## 5. 本切片非目标

- 公众号/服务号/订阅号、企业模板、长期订阅、客服消息节奏  
- 二孩、隔代主账号、社区、商城、问诊对话、穿戴设备  
- 把父亲/母亲内容拆成两个互不可见的收件箱  
- T0 之后催更、破静音、断票后用别的通道硬送  
- 1–7 岁写细、多城市政策百科、商品种草  
- 独立 App、短信

## 6. 会卡住实现的问题（短）

锁定项不再问。仅当没有答案就无法上架/无法写细稿时：

1. **个人/个体小程序**过审类目、以及后台能申请到的一次性订阅模板名称——以微信实际可过的为准，通道仍是 A。  
2. **细稿**（孕晚–1 岁）是否已有指定的公开权威来源与法务免责原文；没有则编辑无法定稿，骨架阶段可先上。
