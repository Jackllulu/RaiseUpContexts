# RaiseUpContexts · 新生日历

给第一次当父母、父母对等的家庭：从怀孕到孩子 7 岁，按事项的最早需要日（T0）把该准备、该学的内容送到微信小程序。每条标明**给父亲**或**给母亲**；任意一个已登录的微信都能看到两套副本。

产品文档在 [`docs/`](./docs/)。

## 可测演示（请用这个，不要等微信审核）

浏览器 Web App，镜像小程序 12 屏与底栏「日历 · 家庭 · 我的」。样例内容与模拟订阅票都在本地，**无真实微信 API**。

```bash
npm start
```

然后打开 <http://127.0.0.1:4173/>（需要 Python 3，仅作静态文件服务）。

跑调度单测：

```bash
npm test
```

### 建议点选路径

1. 启动 → 创建家庭：上海、预产期或生日、家长可跳过、订阅可跳过  
2. 或点页右「填入孕 32 周演示家」立刻看到孕晚细稿  
3. 日历：全部 / 仅父亲 / 仅母亲（筛选不是权限）；点进详情勾选；补课包  
4. 家庭：孩子档案、父母资料、预设标签 + 1 个自定义  
5. 我的：续票、静音、邀请第二微信（同浏览器模拟微信 B）、免责、退出  
6. 拨「演示日期 / 小时」验证 T-14/T-7/T0、夜间顺延、无票横幅  

待确认项见 [`docs/demo-open-questions.md`](./docs/demo-open-questions.md)，页内也有「待确认」条。

`miniprogram/` 只是微信小程序空壳（页面名对齐 IA），**不能**代替浏览器演示。
